About Our Project

Our goal is to build an accessible, beautifully organized digital space for readers to discover, track, and review great books from around the world.

This project was created as part of Front-End Development Assignments 1 & 2 at Astana IT University, focused on HTML semantics, CSS box model, Flexbox, and Grid.

About the Team Member

Altyn Abdinurova

Role: Front-End Developer

I am a second-year Software Engineering student at Astana IT University (AITU). I graduated from Lyceum No. 1 and I love listening to music. I designed and implemented the main layout, catalog structure, and global styling for the Book Collection platform.

Responsibilities Included:

  • HTML structure & semantic layout across all pages
  • Shared stylesheet creation and CSS selector configuration
  • Data tables and form integration
  • Flexbox & Grid responsive layout design
  • Reading-streak widget (JS + localStorage)
  • Bookmark / shelf system (JS + localStorage)
  • Deployment via GitHub Pages
